# Model Farm 0.9.20

Launch-readiness pass: the panel now hands you the exact MCP client
configuration for this installation, and a client can launch the server while
the app's panel is already open.

## Connect an MCP client

- The Overview has a **Connect an MCP client** card below the live activity
  feed. It shows the `mcpServers` block for *this* installation — the command,
  the `dist/index.js` argument and, in the installed app, the
  `ELECTRON_RUN_AS_NODE` and `TOOLBOX_MCP_HOME` environment — with a copy
  button.
- The installed-app configuration now includes `TOOLBOX_MCP_HOME`, so a client
  launched from the card reads the same settings and credential references as
  the app you have open.
- The portable build has no stable path to offer (it unpacks to a temporary
  folder on every run). Its card says so and points at the installer or a
  source checkout instead of showing a configuration that would break.
- The card is generated by `clientLaunch()` and served in `/api/catalog`, so
  the panel and any client see one source of truth.

## Busy panel port

- An MCP client launching the server while the app's panel already holds 3851
  no longer fails with "address already in use". The second server moves to a
  free loopback port and prints the address; the stdio connection is
  unaffected.

## Documentation

- New [SECURITY.md](https://github.com/acsdd/toolbox-mcp/blob/main/SECURITY.md): how to report a vulnerability privately,
  what is in scope, and what is not (unsigned binaries, a local attacker with
  your user rights, third-party runtimes and models).
- New [CONTRIBUTING.md](https://github.com/acsdd/toolbox-mcp/blob/main/CONTRIBUTING.md): sibling checkout, build and test
  commands, and the rules for a pull request (no secrets, `.accounts` or local
  settings; tests for behaviour changes).
- README: release, CI and license badges, a short quick start, and links to
  the install, security and contributing guides.
- The GitHub Pages landing page gained a three-step start, the runtime and
  privacy facts, a fresh panel screenshot and the document links.
- [docs/install.md](https://github.com/acsdd/toolbox-mcp/blob/main/docs/install.md) matches the generated configuration and
  explains the busy-port fallback and the portable caveat.

## Verification

- 330 tests in 76 suites pass; TypeScript typecheck clean.
- Packaged probes on 0.9.20: smoke test green (sandboxed window, loopback-only
  panel, 37 tools, 4-row scorecard, connect card rendered); install probe
  passed against the unpacked payload and the extracted Setup payload (37
  tools, matching panel catalogue, read-only call, MCP client journey);
  secondary-runtime probe detected 10 runtimes and passed switching,
  unknown-runtime refusal, removal guard and restore.
